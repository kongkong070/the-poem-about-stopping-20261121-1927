A short original poem about agency — the power to stop and to stay — written for the [make.fun bounty](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

`main.ts` (Node 22, stdlib only, no network) writes the poem to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` when set). The output is deterministic: every run produces the same 265-character text.
